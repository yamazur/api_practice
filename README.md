# Задание

1. Склонировать себе и развернуть проект (инструкция в репозитории)
2. На языке программирования Python (версия на ваш выбор) создать проект из пяти API-
автотестов для всех точек доступа к приложению (только положительные кейсы)
3. Допустимо добавление новых тест-кейсов в уже существующий проект из предыдущего
задания
4. В проекте использовать: 
HTTP-клиент / библиотека для API-тестов: requests (для отправки HTTP-запросов)
Сериализация/десериализация: стандартный модуль json или библиотека pydantic (все полученные данные обязательно должны быть десериализованы в Python-объекты/модели)
Тестовый фреймворк: pytest
Менеджер зависимостей и сборщик: pip + requirements.txt
5. Результаты на проверку оформить в виде Merge Request/Pull Request (!!!) ветки в которой вы вели разработку в главную на Gitlab/GitHub
6. Дополнительное задание No1: Реализовать формирование отчетов Allure.
7. Дополнительное задание No2: Реализовать параллельный запуск тестов.
8. Дополнительное задание No3: Реализовать запуск в системе CI/CD.
